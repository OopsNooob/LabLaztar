# Git Merge Conflicts - Learning Guide

## Scenario 1: Merge Conflict - Choose Incoming or Current Changes
- Cách xử lý: Chọn một trong 2 phiên bản (Accept Incoming / Accept Current)

## Scenario 2: Merge Conflict - Manual Resolution Required
- Cách xử lý: Sửa conflicts manually, rồi commit

Hãy follow hướng dẫn từng bước trong các thư mục tương ứng.
